ARZANO - concept website v2 (pitch prototype)
=============================================
Open index.html in a browser (double-click works; fonts need internet).
Arabic home page: ar/index.html

Pages
- index.html          Home: hero, collections, occasion finder, heritage, red carpet, craft,
                      piece of the season, private-viewing booking (day + time picker), trade
- collection.html     All 14 pieces; filter by type and collection (?f=earrings&c=melange)
- pieces/*.html       One page per piece: zoom, specs, WhatsApp, booking, related pieces
- boutiques.html      Find Arzano: retail partners, private appointments by city, trade fairs
- ar/index.html       Full Arabic (right-to-left) home page with Arabic booking + concierge
- 404.html            Not-found page
- sitemap.xml, robots.txt, site.webmanifest, assets/favicon.svg

How it is built
- The pages are generated by a small script so header, footer, SEO tags and the catalogue
  stay consistent. Edit the sources, then rebuild:
      python tools/build.py
  tools/pages/        page sources            tools/partials/   header, footer, head, concierge
  tools/templates/    piece page template     tools/catalogue.json   collections + pieces
- Images: originals in tools/img-src. To regenerate AVIF/WebP/JPEG sizes (needs Pillow):
      python tools/make_images.py tools/img-src assets/img/r tools/images.json
- No frameworks, no jQuery, no trackers. assets/js/main.js is plain JavaScript.

Before showing / going live
- Set Arzano's WhatsApp Business number in assets/js/main.js (WA_NUMBER). Until then WhatsApp
  links open WhatsApp without a recipient.
- Product names, specs and metals are placeholders based on Arzano's captions - confirm all.
- The concierge says Mélange starts "from around US$1,800" (based on The 1916 Company's
  listings). Arzano must approve before this is shown publicly.
- Retail partners shown: Kooheji (Bahrain, from Arzano's Instagram) and The 1916 Company (US,
  from their website). Confirm the list with Arzano.
- concierge@arzano.com is a placeholder address.
- Red-carpet photos are press images Arzano reposted; get licences before a public launch.
- Forms, booking and concierge are front-end demos (no backend yet).
- Production: self-host the fonts, serve over HTTPS with compression and caching, and add
  analytics only behind a consent banner.

Run locally
- From this folder:  python -m http.server 8000   then open http://localhost:8000

Deploy (Vercel)
- vercel.json copies only the website files into dist/ and serves that folder, so the
  tools/ sources are never published. Every page is sent with "noindex" so the prototype
  stays out of search results; remove that header when the site moves to arzano.com.

Client documents (audit, project update, page-by-page PDF) are kept outside this repo.
